📱 Pasul 1: Instalează aplicația pe telefon (iOS & Android)

  • Pe iOS (Safari): apasă pe butonul Share (Partajare) și alege „Add to Home Screen” (Adaugă pe ecranul principal).
  • Pe Android (Chrome): apasă meniul ⋮ din colțul dreapta-sus și alege „Install app” (Instalează aplicația) sau „Add to Home screen”.

📲 Pasul 2: Alerte Instant pe telefon cu ntfy.sh (Fără cont)

  • Instalează aplicația gratuită ntfy din App Store (iOS) sau Google Play (Android).
  • Apasă „+” și abonează-te la topicul configurat pentru acest tracker (sau la unul propriu dacă găzduiești propria copie pe GitHub).
  • Pentru administrator: în GitHub → Settings → Secrets and variables → Actions adaugă secretul NTFY_TOPIC.

✈️ Opțional: Alerte prin Telegram Bot API

  • Creează un bot prin @BotFather pe Telegram și copiază token-ul.
  • Adaugă în GitHub Actions Secrets variabilele TELEGRAM_BOT_TOKEN și TELEGRAM_CHAT_ID.
